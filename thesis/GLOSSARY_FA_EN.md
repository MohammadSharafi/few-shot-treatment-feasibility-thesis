# English ↔ Formal Persian glossary (thesis)

Edit this file to enforce consistent terminology. **Code identifiers, table names, and `MIMIC-IV` stay in English.**

| English | فارسی (پیشنهادی) |
|--------|------------------|
| treatment feasibility | امکان‌پذیری درمان / تحقق‌پذیری ترخیص درمانی |
| few-shot learning | یادگیری با دادهٔ کم (few-shot) |
| federated learning | یادگیری فدرال / یادگیری توزیع‌شده |
| meta-learning | فرا یادگیری |
| prototypical networks | شبکه‌های نمونه‌ای |
| Symptom Tokens | توکن‌های علائم (Symptom Tokens) |
| electronic health records (EHR) | پروندهٔ سلامت الکترونیک |
| intensive care unit (ICU) | بخش مراقبت‌های ویژه |
| AUROC | AUROC (نگهداری لاتین) |
| stacking | انباشت / meta-learner انباشتی |
| knowledge distillation | تقطیر دانش |

| held-out test set | مجموعهٔ آزمون نگه‌داشته‌شده |
| ablation | حذف تدریجی اجزا |

## یادداشت نسخهٔ فارسی (`thesis_fa.tex`)

- فصل‌های **مقدمه**، **جمع‌بندی**، **آزمایش‌ها** و **تحلیل داده** در `chapters_fa/` به‌صورت پاراگرافی رسمی فارسی هستند.
- فصل‌های **روش‌شناسی**، **پیشینه**، **نتایج** و **بحث** فعلاً **عنوان فارسی** دارند ولی متن پاراگرافی داخل `\begin{latin}...\end{latin}` به انگلیسی مانده تا معادلات، الگوریتم‌ها و جداول بدون تداخل با `\lr` یکپارچه کامپایل شوند؛ برای ارسال نهایی می‌توان آن بلوک‌ها را به‌تدریج با ترجمهٔ کامل جایگزین کرد.
